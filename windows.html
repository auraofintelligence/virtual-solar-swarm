Launch windows

You cannot leave for another world whenever you like. The cheap path is a long curve that arrives where the target will be, so Earth and the target have to line up first, like merging into moving traffic. Each lining-up is a launch window. But the schedule is not fixed: buy more push and the whole timetable bends. Slide the dial and watch.
